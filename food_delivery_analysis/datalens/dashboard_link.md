## Описание дашборда

Дашборд включает 7 ключевых визуализаций:

1. **DAU** - ежедневная активность пользователей
2. **Conversion Rate** - коэффициент конверсии  
3. **Средний чек** - по месяцам
4. **LTV ресторанов** - топ-3 по доходности
5. **Популярные блюда** - вклад в LTV
6. **Retention Rate** - удержание пользователей
7. **Retention по месяцам** - когортный анализ

## Назначение
Дашборд предназначен для мониторинга состояния клиентской базы и выявления точек роста бизнеса.
